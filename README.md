# nn-from-scratch
This project is an attempt to build my own neural network framework from scratch. I want to gain a deeper understanding of how neural networks work and implement key deep learning concepts myself.


## Project Structure

```
nn-from-scratch/
├── src/                          # Main framework code
│   ├── __init__.py               # Module initialization
│   ├── layers.py                 # Implementation of layers (e.g., Dense, Conv)
│   ├── activations.py            # Activation functions (e.g., ReLU, Sigmoid)
│   ├── losses.py                 # Loss functions (e.g., MSE, Cross-Entropy)
│   ├── optimizers.py             # Optimizers (e.g., SGD, Adam)
│   └── network.py                # Main class for the neural network
├── notebooks/                    # Jupyter Notebooks for experiments
│   └── experiments.ipynb         # Your playground for prototyping
├── tests/                        # Unit tests
│   └── test_layers.py            # Example test for layers
├── docs/                         # Documentation
│   └── architecture.md           # Description of the architecture
├── requirements.txt              # Dependencies (e.g., numpy, matplotlib)
├── setup.py                      # Optional: For installation as a package
└── README.md                     # Project overview (already present)
```
